# 라즈베리파이 5 설치 — 정식 게임기 (책상 2대 = 파이 1대)

정식 제작 게임기의 제어부 설치 절차다. 파이 한 대가 모니터 두 대를 한 화면(3840×1080)으로
쓰고, 웹앱이 왼쪽 반 = 책상 1, 오른쪽 반 = 책상 2 로 나눠 쓴다. 버튼 10개(책상마다
빨·노·초·파·흰)는 USB 아케이드 인코더 하나에 다 물린다.

파일럿 때의 우노 Q 구성(App Lab 브리지·감시 스크립트)은 여기서 **전부 필요 없다.**
버튼이 게임패드로 잡히고, 파이는 전원이 들어오면 무조건 켜지며, HDMI 2개가 보드에 직접 있다.

```
 [책상 1 버튼 5] ─┐                          ┌─ HDMI0 ──▶ 모니터 1 (왼쪽)
 [책상 2 버튼 5] ─┴─ USB 인코더 ─USB─▶ 파이 5 ─┤
                                              ├─ HDMI1 ──▶ 모니터 2 (오른쪽)
                                              └─ USB 사운드카드 ─3.5mm─▶ 스피커
```

## 1. 준비물

부품 견적표 그대로. 이 문서에서 쓰는 것만 다시 적으면:

| | |
|---|---|
| Raspberry Pi 5 8GB + 패시브 케이스 + 27W 공식 어댑터 | |
| 마이크로SD 32GB 고내구성 ×2 | 1장 운영, 1장 복제 예비 |
| 마이크로HDMI→HDMI 케이블 ×2 | 파이 쪽이 **마이크로** HDMI |
| USB 사운드카드 (3.5mm 출력) | 파이 5 에 3.5mm 단자가 없다 |
| USB 제로딜레이 인코더 + 2선 케이블 | 버튼 10개 |
| 설정할 때만: USB 키보드·마우스, 인터넷(랜선 또는 Wi-Fi) | 설치 뒤엔 빼도 된다 |

## 2. SD 카드 굽기 (PC 에서)

**Raspberry Pi Imager** (raspberrypi.com/software) 로:

1. 기기: Raspberry Pi 5 · OS: **Raspberry Pi OS (64-bit)** — 데스크톱 포함 버전 · 저장소: SD 카드
2. "설정 편집" 에서:
   - 호스트 이름 `torus-1` (2호기는 `torus-2`)
   - 사용자 이름 `torus`, 비밀번호는 기관 규칙대로 (아래 예시는 `torus` 사용자 기준)
   - Wi-Fi: 문화관 네트워크 (설치·업데이트용. 없어도 랜선이면 된다)
   - 로캘: `Asia/Seoul`, 키보드 `us`
   - 서비스 탭: **SSH 켜기** (비밀번호 인증)
3. 굽기. 끝나면 파이에 꽂고, 모니터 1대·키보드·마우스만 먼저 연결해서 켠다.

## 3. 첫 부팅 설정

첫 부팅은 1~2분 걸린다. 데스크톱이 뜨면 터미널(Ctrl+Alt+T)에서:

```bash
sudo raspi-config
```

| 메뉴 | 설정 | 이유 |
|---|---|---|
| **Advanced Options → Wayland → X11** | X11 선택 | 창 하나를 모니터 두 대에 펼치려면 X11 이어야 한다. 파이 5 기본은 Wayland |
| **System Options → Boot / Auto Login → Desktop Autologin** | 켜기 | 전원만 넣으면 로그인 없이 화면이 뜨게 |
| **Display Options → Screen Blanking** | 끄기 | 전시 중 화면이 꺼지지 않게 |

Finish → 재부팅. 재부팅 뒤 패키지:

```bash
sudo apt update && sudo apt install -y chromium git unclutter x11-xserver-utils
```

(`chromium` 이 없다고 하면 `chromium-browser`.)

## 4. 게임 설치

```bash
git clone https://github.com/i20091119-ai/2026memory.git ~/torus-memory-game
cd ~/torus-memory-game
bash scripts/install-kiosk.sh
```

스크립트가 파이임을 알아보고 이렇게 한다:

- 웹서버(`torus-web`)를 사용자 서비스로 등록
- 부팅 자동시작에 **`scripts/pi-kiosk.sh`** 를 건다 — 모니터 2대 배치, USB 사운드카드를
  기본 출력으로, 절전 해제, 커서 숨김, 크로미움을 **3840×1080 창**으로
- Openbox 규칙으로 크로미움 창 테두리를 없앤다 (`~/.config/openbox/lxde-pi-rc.xml`)
- SD 쓰기를 줄인다: 로그는 램에만, 스왑 끔, 브라우저 캐시는 `/dev/shm`
- 우노 Q 용 브리지·감시는 걸지 않는다

끝나면 **전원을 끄고** 모니터 2대·인코더·사운드카드를 다 꽂은 뒤 켠다.
타이틀 화면이 양쪽 모니터에 각각 뜨면 성공이다.

> 모니터는 **HDMI0(USB-C 전원 단자 바로 옆)이 왼쪽 책상**이다. 좌우가 바뀌어 보이면
> 케이블 두 개를 서로 바꿔 꽂으면 된다.

## 5. 인코더 배선

인코더 기판 아래 줄의 2핀 커넥터 열이 버튼 입력이다. 인쇄된 번호(K1, K2 … 또는 1, 2 …)
순서대로:

| 인코더 입력 | 버튼 | 인코더 입력 | 버튼 |
|---|---|---|---|
| K1 | 책상 1 빨강 | K6 | 책상 2 빨강 |
| K2 | 책상 1 노랑 | K7 | 책상 2 노랑 |
| K3 | 책상 1 초록 | K8 | 책상 2 초록 |
| K4 | 책상 1 파랑 | K9 | 책상 2 파랑 |
| K5 | 책상 1 **흰색** | K10 | 책상 2 **흰색** |

- 2선 케이블의 스페이드 단자를 마이크로스위치 **COM 과 NO** 에 꽂는다 (NC 에 꽂으면 눌린 채로 인식된다).
- 극성 없다. 버튼마다 GND 가 따로 가므로 GND 데이지체인이 없다.
- 책상 2 의 5개는 십색선으로 2m 연장 (인코더 동봉 선을 가운데서 잘라 WAGO 로 잇는다).
- 버튼 LED(12V)는 인코더와 무관하다 — 책상마다 12V 어댑터에 병렬.

번호가 안 맞아 보이면 (예: 책상 1 빨강이 노랑으로 인식) 선을 바꿔 꽂는 게 제일 빠르다.
정 안 되면 `js/config.js` 의 `GAMEPAD_MAPS` 에서 번호표를 고친다.

**확인**: 게임 타이틀에서 버튼을 누르면 그 좌석만 반응해야 한다. 흰색은 옆 좌석에
"도전을 신청했어요" 를 띄운다.

## 6. 소리

USB 사운드카드의 **초록(출력) 단자** ↔ 스피커 AUX. `pi-kiosk.sh` 가 부팅 때마다 USB
사운드카드를 기본 출력으로 잡고 볼륨을 100% 로 둔다. 스피커 노브로만 조절한다.

소리가 안 나면:

```bash
bash scripts/pi-kiosk.sh --audio      # 다시 잡기 + 로그
wpctl status                          # Sinks 에 USB 카드가 보이는지
speaker-test -t wav -c 2              # 왼쪽/오른쪽 음성. Ctrl+C
```

효과음은 왼쪽 책상 소리가 왼쪽 스피커, 오른쪽이 오른쪽에서 난다.

## 7. 예비 SD 카드 만들기 (꼭)

게임기가 완전히 세팅된 뒤에 한다. SD 카드가 파이의 유일한 소모품이라, 복제본이 있으면
고장 났을 때 **카드만 바꿔 끼우면 1분 복구**다.

가장 쉬운 방법 — 파이 데스크톱의 **SD Card Copier** (메뉴 → 보조 프로그램):
1. USB SD 리더에 예비 카드를 꽂고 파이 USB 에 연결
2. Copy From: 내장 SD(`/dev/mmcblk0`) → Copy To: 리더의 카드 → Start
3. 5~10분. 끝나면 빼서 봉투에 "메모리 게임기 예비 — 날짜" 라고 적어 서랍에.

PC 에서 하려면 Win32DiskImager 로 원본을 `.img` 로 읽은 뒤 예비 카드에 쓴다.

파이 3대(메모리·모스·예비)가 같은 이미지에서 출발해도 된다 — 호스트 이름만
`sudo raspi-config` 에서 바꾼다.

## 8. 업데이트

```bash
cd ~/torus-memory-game && git pull && sudo reboot
```

재부팅이 싫으면 크로미움만: `pkill -f chromium; bash scripts/pi-kiosk.sh &`.
설치 스크립트를 고친 업데이트면 `bash scripts/install-kiosk.sh` 를 한 번 더.

## 9. 확인 체크리스트

- [ ] 전원만 꽂으면 양쪽 모니터에 타이틀이 뜬다 (로그인·클릭 없이)
- [ ] 책상 1 버튼은 왼쪽 화면만, 책상 2 버튼은 오른쪽 화면만 움직인다
- [ ] 흰색 → 옆 화면에 도전 프롬프트, 옆에서 흰색 → 대결 시작
- [ ] 소리가 좌우 스피커에서 각각 난다
- [ ] 크로미움 창에 테두리·주소창이 없다
- [ ] 콘센트를 뽑았다 꽂아도 그대로 다시 뜬다
- [ ] 예비 SD 카드를 만들어 두었다

## 10. 문제 해결

| 증상 | 확인 |
|---|---|
| 창이 한쪽 모니터에만 뜨거나 가운데가 잘림 | `bash scripts/pi-kiosk.sh --layout` 후 `xrandr` 로 두 출력이 0x0, 1920x0 인지. Wayland 세션이면 X11 로 (3절) |
| 창에 테두리가 있다 | `~/.config/openbox/lxde-pi-rc.xml` 에 `torus-kiosk` 규칙이 있는지. 없으면 `install-kiosk.sh` 재실행 후 로그아웃/로그인 |
| 버튼이 안 먹는다 | `ls /dev/input/js*` 에 장치가 있는지 → 없으면 인코더 USB. 있으면 브라우저를 한 번 클릭해 준 뒤(첫 입력 전엔 게임패드가 노출되지 않는다) 다시 |
| 버튼 좌석이 뒤바뀜 | 인코더 K1~K5 / K6~K10 배선 확인 (5절) |
| 소리 없음 | 6절. USB 카드 초록 단자인지, 스피커 노브(전원 겸용)가 켜져 있는지 |
| 화면이 꺼진다 | `raspi-config` Screen Blanking 끔 + `pi-kiosk.sh` 의 `xset s off -dpms` 가 로그(`~/torus-kiosk.log`)에 오류 없이 지나갔는지 |
| 기록 CSV 꺼내기 | 타이틀에서 노랑+초록 3초 → 초록(CSV) → `~/Downloads/` |

로그: `~/torus-kiosk.log` (화면 띄우기), `journalctl --user -u torus-web` (웹서버).
