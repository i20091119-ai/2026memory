배선도 — 토러스와 즐기는 랜덤 메모리 게임

아두이노 우노 Q + 100파이 아케이드 버튼 4개. 조립하면서 보는 용도. 회로는 두 개가 완전히 따로 있다 — 스위치 회로(우노 Q)와 LED 회로(12V). 둘을 절대 연결하지 않는다.

먼저 읽을 것

① 마이크로스위치는 COM · NO 두 단자만 쓴다. NC 를 쓰면 반대로 동작한다.
② 버튼 순서 0=빨강 1=노랑 2=초록 3=파랑 은 함체 왼쪽→오른쪽 순서이고, 펌웨어·웹앱 전체에서 고정이다. 절대 바꾸지 않는다.
③ 배선은 전원을 모두 뽑은 상태에서 한다.

1. 버튼 스위치 → 우노 Q

인덱스버튼 (왼쪽→오른쪽) 스위치 NO →스위치 COM →키보드
0빨강 D2GND (4개 데이지체인)1
1노랑 D32
2초록 D43
3파랑 D54

평상시 HIGH, 누르면 LOW 다 (내부 풀업). 우노 Q 헤더는 3.3V 로직이지만 단순 스위치 입력이라 영향이 없다.

단자에 선을 무는 방법은 두 가지다. 파스톤(평형) 암단자 압착 — 압착펜치가 필요하지만 뺐다 꽂기 쉽다. 납땜 — 단자 구멍에 선을 꿰고 지진다. 어느 쪽이든 수축튜브로 절연할 것. 안 쓰는 NC ② 가 바로 옆이라 닿으면 버튼이 반대로 동작한다. 납땜은 3초 안에 끝낸다 — 오래 지지면 스위치 내부가 녹아 접점이 틀어진다.

2. 버튼 LED (12V) — 우노 Q 와 무관한 별도 회로

이 회로를 우노 Q 에 연결하지 않는다. 12V 가 3.3V 로직 핀에 닿으면 보드가 망가진다. 스위치 배선과 물리적으로 분리해서 정리한다.

LED 에 저항이 필요한가

LED 몸통에 4~12V 처럼 전압이 범위로 적혀 있으면 저항이 내장된 램프 모듈이라 12V 에 바로 물려도 된다. 맨 LED 알이면 저항 없이 물리는 순간 탄다. 표시가 없어 판단이 안 서면 LED 마다 470Ω 을 직렬로 하나씩 넣고 시작하면 어느 쪽이든 안전하다.

470Ω 을 넣고 켜 봤을 때정체어떻게
충분히 밝다맨 LED (약 21mA — 정격)그대로 둔다
많이 어둡다저항 내장 모듈저항을 빼고 12V 직결로 바꾼다

저항은 LED 마다 하나씩 넣는다. 4개에 공통 저항 하나를 쓰면 개체 편차 때문에 한 개로 전류가 몰려 그것만 밝고 빨리 죽는다. 정격 전력은 1/2W 이상을 쓴다 (1/4W 는 여유가 없다).

3. 전원 · 영상

화면이 안 나올 때 점검 순서

  1. 허브가 DP Alt-Mode 를 지원하는가 (충전 전용 허브는 영상이 안 나온다)
  2. 모니터 입력 소스가 맞는가
  3. 우노 Q 출력 한계(HD+ 720×1680@60Hz)를 넘지 않는가

4. 신호가 흐르는 길

5. 조립 순서

  • 전원을 전부 뽑는다.
  • 버튼 4개를 함체에 왼쪽부터 빨강·노랑·초록·파랑 순으로 끼운다.
  • 스위치 몸통의 각인으로 COM ① · NC ② · NO ③ 위치를 확인한다. 각인이 없는 스위치라면 멀티미터 도통 모드로 눌렀을 때만 붙는 쌍을 찾는다.
  • NO ③ → D2·D3·D4·D5 를 왼쪽 버튼부터 차례로 연결한다. 신호선은 버튼 색과 같은 색 전선을 쓰면 나중에 열어 봐도 한눈에 안다.
  • COM ① 4개를 데이지체인으로 잇고(검은 선), 그 끝을 GND 에 연결한다. NC ② 는 비워 둔다.
  • 납땜·압착 자리에 수축튜브를 씌운다. 옆 단자에 닿으면 오작동한다.
  • LED 4개를 12V 어댑터에 병렬로 연결한다 (극성 주의, 필요하면 저항 직렬). 우노 Q 와는 연결하지 않는다.
  • USB-C 허브에 PD 어댑터·모니터·우노 Q 를 연결한다.
  • 함체에 넣기 전에 전원을 넣어 버튼 4개가 순서대로 잡히는지 먼저 확인한다. 닫고 나면 손대기 어렵다.
  • 함체 뒷면 노치(40×14mm)로 케이블을 빼고 정리한다.

6. 배선 확인

위에서부터 짚어 내려가면 어디가 끊겼는지 나온다.

  1. 스위치 — 멀티미터로 COM–NO 가 눌렀을 때만 붙는지.
  2. 스케치 — 시리얼 모니터(115200)에서 버튼을 누르면 B0 D / B0 U 가 뜨는지.
  3. 브리지 — python3 firmware/button_bridge/python/main.py -v 로 띄우고 로그 확인.
  4. 웹앱 — 화면 오른쪽 아래 점이 초록이면 연결됨. 회색이면 미연결(이때도 키보드 1234 로는 플레이된다).
