전원 버튼 배선 — 파이 5 J2 (해설사용 켜기/끄기)

연결

  1. 푸시버튼 뒤 핀 2개에 선 두 가닥(십색선 15cm) 납땜. 극성 없음.
  2. 파이 케이스 뚜껑 열기. 보드 왼쪽 아래 모서리에 "J2" 라고 인쇄된 작은 패드 2개 찾기 (사진 참조 — 전원 버튼 바로 옆, 배터리 커넥터 J5 와 붙어 있음).
  3. 선 두 가닥을 J2 두 패드에 각각 납땜. 어느 선이 어느 패드든 상관없다.
  4. 선을 케이스 틈으로 빼고 뚜껑 닫기. 버튼은 책상 스커트 뒷문 옆 옆판에 Ø12 구멍 뚫어 너트 고정.
  5. SSH: cd ~/torus-memory-game && git pull && bash scripts/install-kiosk.sh && sudo reboot

동작

  • 켜져 있을 때 한 번 누름 → 정상 종료 (10초쯤 뒤 화면 꺼짐, 빨간불만 남음)
  • 꺼져 있을 때 한 번 누름 → 켜짐 (어댑터는 꽂아 둔 채)
  • 먹통일 때 5초 이상 누름 → 강제 종료 (비상용)
J2 는 전원 버튼 스위치 접점이지 전원 입력이 아니다. 12V 나 5V 를 절대 넣지 말 것 — 버튼의 두 핀을 그냥 잇기만 한다.
납땜이 어려우면 대안: 40핀 헤더의 5번(GPIO3)·6번(GND) 핀에 암-암 점퍼선으로 버튼을 물리고 /boot/firmware/config.txt 끝에 dtoverlay=gpio-shutdown 한 줄. 끄기는 확실히 되고, 켜기는 실물로 한 번 시험. (5번 핀 = USB 쪽에서 봐서 바깥 줄 3번째, 6번 = 그 안쪽.)
