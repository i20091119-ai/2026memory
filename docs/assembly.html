조립 가이드 ① — 오늘: 파이 켜기

책상이 오기 전에 책상 위에서 한 세트를 완성한다. 1일차는 파이 + 모니터 1대 + 키보드만. 자세한 명령은 docs/raspberry-pi-setup.md.

케이스 조립 (먼저)

  1. 마이크로SD 를 먼저 굽는다 (PC, Raspberry Pi Imager — 2절). SD 슬롯은 보드 밑면이라 케이스에 넣기 전에 꽂아야 편하다.
  2. 알루미늄 케이스 윗뚜껑 안쪽의 돌출부가 칩 위에 오는 자리에 써멀패드: CPU(큰 정사각형 칩) 1.0mm, 그 옆 작은 칩들(램·전원 IC) 0.5mm. 패드 보호필름 양면 다 벗긴다.
  3. 보드를 케이스 바닥에 놓고 뚜껑 덮어 나사 4개. 뚜껑 돌출부가 칩에 닿아야 방열이 된다 — 조이고 나서 케이스가 살짝 따뜻해지면 정상.

1차 연결 — 이것만 꽂고 켠다

  1. 마이크로HDMI→HDMI 케이블: 파이 HDMI0(전원 옆) ↔ 모니터
  2. USB 키보드·마우스: 아무 USB
  3. (설정 때만) 랜선 또는 Wi-Fi — git clone 에 인터넷이 필요
  4. 맨 마지막에 27W 어댑터를 USB-C 에 — 꽂는 순간 켜진다 (전원 버튼 없음)
켜지면 빨간불 → 초록불 깜빡 → 20초쯤 뒤 바탕화면. 바탕화면이 뜨면 3절(X11 전환)·4절(게임 설치)로. 초록불이 안 깜빡이면 SD 가 안 꽂혔거나 안 구워진 것.

1일차 끝나는 기준

  • 어댑터만 꽂으면 로그인·클릭 없이 게임 타이틀이 혼자 뜬다
  • 키보드 1·2·3·4 로 게임이 된다 (버튼은 2일차)
  • 크로미움 창에 테두리·주소창이 없다
어댑터는 꼭 파이 공식 27W. 휴대폰 충전기면 "저전압" 경고가 뜨고 USB 가 꺼진다. 파일럿의 우노 Q 와 달리 허브가 없으니 전원·HDMI 가 전부 보드에 직접 꽂힌다.

조립 가이드 ② — 2·3일차: 전체 연결

1일차가 끝난 뒤. 버튼 10개는 책상 없이 바닥에 늘어놓고 배선·확인까지 끝낸다.

꽂는 순서

  1. 모니터 2 를 HDMI1 에 → 재부팅 → 한 화면이 좌우로 갈려 뜨는지
  2. 인코더 USB → 파이 USB (파란 USB3 아무 곳)
  3. 버튼 10개 배선 (오른쪽 그림) → 크로미움에서 localhost:8000/docs/buttontest.html 열어 하나씩 누르기
  4. USB 사운드카드 → 파이 USB. 초록 단자 → 3.5mm–RCA 선 → 액티브 스피커 입력. 액티브 ↔ 패시브는 동봉 스피커선
  5. 12V 어댑터 → 단자대 → 버튼 LED 10개 병렬
  6. 이틀 켜 두고 vcgencmd measure_temp. 끝나면 예비 SD 복제(7절)

확인 화면 — buttontest.html 에서 누른 버튼에 불이 들어온다. 엉뚱한 자리에 불이 들어오면 그 두 선을 인코더에서 바꿔 꽂는다 (설정 수정 불필요). 눌렀는데 계속 켜져 있으면 NC 에 꽂은 것 → NO 로.
책상에 들어갈 때 — 책상 2 쪽 5개는 선을 가운데서 잘라 십색선으로 2m 연장(WAGO). 지금은 짧은 채로 바닥에서 확인만.
