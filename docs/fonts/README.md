# 동봉 글꼴

## 이사만루체 (GongGothic Light / Medium / Bold)

- 제작: 공게임즈 × 폰트릭스 (2020년 한글날 배포)
- 파일: `GongGothicLight.woff`, `GongGothicMedium.woff`, `GongGothicBold.woff`
- 출처: 눈누(noonnu.cc) 웹폰트 배포본 (`projectnoonnu/noonfonts_20-10`)
- 라이선스: 개인·기업 누구나 상업적 용도를 포함해 무료로 쓸 수 있다. 글꼴을 임의로 수정해 유료로 판매하는 것은 금지. 지적재산권은 공게임즈에 있다.
- 쓰는 곳: `docs/labels.html` (버튼 안내 라벨). CSS `font-family: 'esamanru'`, 굵기 300/500/700.

오프라인 키오스크 원칙에 따라 CDN 대신 파일을 저장소에 같이 둔다.
