버튼 4개, 손 하나면 끝
4세부터 어른까지 · 한 판 3~5분

화면에 나온 것을 외웠다가, 그 순서대로 버튼을 누릅니다. 1개부터 시작해 4개까지 늘어나고, 20라운드를 다 맞히면 완주!

  • 빨강 = 색상 — 나온 색깔 순서를 그대로
  • 노랑 = 숫자 — 나온 숫자를 기억
  • 초록 = 모양 — 모양만 기억, 색은 함정
  • 파랑 = 혼합 — 셋이 마구 섞여서
  • 흰색 = 도전 — 옆 사람과 대결
1게임 고르기 — 카드와 같은 색 버튼을 누르면 시작
2외우기 — 큰 화면에 하나씩 차례로 나옵니다
3따라 누르기 — 외운 순서대로 버튼을. 목숨은 3개
4완주! — "당신의 기억폭" 카드로 기억 과학 한 스푼

둘이서 대결흰색 버튼

옆 책상 사람에게 흰색 버튼으로 도전장을 보내면 그쪽 화면에 "도전에 응하시겠습니까?"가 뜹니다. 상대도 흰색을 누르면 같은 문제가 동시에 나오고, 먼저 다 맞힌 사람이 1점. 먼저 5점을 따면 승리!
