4. 버튼 구멍 단면 — 접착 없이 너트로

  1. 윗면에서 Ø100, 깊이 8 — 플랜지가 쏙 들어가 윗면과 평평. 아이가 가장자리를 못 들춘다.
  2. 아랫면에서 Ø70, 깊이 26 — 너트와 스위치 홀더 자리. 라우터 원형 지그.
  3. 가운데 Ø25 관통 — M24 스템.

남는 살 6mm 는 너트가 조이는 자리일 뿐, 돔을 내리치는 힘은 Ø98 플랜지 바깥 링이 두꺼운 원목에 얹혀 받는다. 상판이 50이면 포켓 깊이를 36으로.

플랜지 허브 둘레의 작은 구멍 4개가 나사 구멍이면 나사 4개(Ø3, 길이 12)로 직접 고정해도 된다. 실물 확인 후 사장님과 결정.

6. 하부 박스 배면 — 도어 · 통풍 · 케이블

  • 도어 380×220, 경첩 + 캠락(열쇠). 안에 파이·인코더·멀티탭·12V 어댑터·(책상 1) 스피커 앰프 짝.
  • 통풍 슬롯 도어 상단·하단 각 3줄 (8×80). 파이 패시브 케이스는 위아래 공기 흐름만 있으면 된다.
  • 케이블 출구 도어 하단 오른쪽 Ø25 (전원선 1줄만 밖으로).
  • 옆면 통로 박스 양 옆면에 Ø30 (바닥에서 120). 두 책상을 붙이면 서로 마주 본다.
  • 스피커 칸 좌우 각 190×230×190 내부. 스피커 뒤 노브 쪽이 도어 칸을 향하게 넣어 손이 닿게.

7. 두 책상 배치 (위에서)

책상 1(왼쪽)에 파이·인코더·멀티탭·스피커 액티브 짝. 책상 2(오른쪽)는 모니터·버튼·스피커 패시브 짝만. 두 책상은 구조가 같다 — 어느 쪽이 1이 될지는 배선으로 정한다.

통로로 지나가는 것: 마이크로HDMI→HDMI 5m 1, 버튼 신호선 5쌍, 스피커선 1, 전원 연장선 1(모니터 2·LED 어댑터).

9. 사장님과 확정할 것

  • 상판 두께 40 인지 50 인지 (50이면 포켓 깊이 36). 등판은 기둥 50×50 + 12mm 판으로 무게를 줄이는 안.
  • 수종. 문화관 기존 교구가 밝은 자작나무 톤이라 그에 맞는 밝은 나무 + 투명 마감.
  • 버튼 실물 스템·플랜지 지름 실측 후 구멍 확정. 라우터 원형 지그 3종(Ø100/Ø70/Ø25).
  • 모니터 실물 VESA 위치와 두께 확인 후 케이블 구멍 위치.
  • 헤더 사인·안내판은 인쇄물 별도 — 판에 붙일 자리(1,430~1,600 / 960~1,020)만 평평하게.
